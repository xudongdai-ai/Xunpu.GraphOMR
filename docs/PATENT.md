# Related Patent Application

This repository is associated with research surrounding the following **published Chinese invention patent application**:

- **Application number:** 202610254567.4
- **Applicant:** Xudong Dai (戴旭东)
- **Publication date shown in the CNIPA notice:** 2026-05-15
- **Title:** 一种基于异质图神经网络的符号化复音数据异常检测与纠错方法及相关设备
- **English descriptive translation:** *Method and Related Apparatus for Anomaly Detection and Correction of Symbolic Polyphonic Data Based on a Heterogeneous Graph Neural Network*

## Scope statement

The application title concerns heterogeneous-graph-based anomaly detection and correction for symbolic polyphonic data. Xunpu GraphOMR additionally contains optical score-image processing, symbol detection, typed relation graphs, reconstruction logic and export tooling.

Accordingly, this repository does **not** claim that every implementation detail, experimental OMR component, or future extension is covered by the patent application's claims. The controlling scope is the official patent application and any claims ultimately examined or granted by the competent patent office.

## Privacy

The original publication notice is **not mirrored in this repository** because the supplied notice contains personal contact and address information that is unnecessary for technical review.

## Research disclosure policy

The public repository contains reproducible baseline code, system architecture, experimental scaffolding, evaluation artifacts and explicit limitations. Private datasets, credentials, unreleased model weights and unrelated proprietary assets are intentionally excluded.
