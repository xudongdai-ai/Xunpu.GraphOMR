# Third-party components

Xunpu GraphOMR depends on third-party Python packages distributed under their respective licenses. The project does not relicense those dependencies.

Core runtime dependencies declared in `pyproject.toml` include NumPy, OpenCV, Pillow, and PyMuPDF. Optional research dependencies include PyTorch, torchvision, and PyTorch Geometric.

Optional external OMR systems, including Audiveris, are **not vendored** in this repository. If used for local comparison, they must be installed separately and remain governed by their own licenses and terms.

No third-party dataset is bundled in the public repository.
